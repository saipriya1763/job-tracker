# Job Application Tracker

A full-stack web application built to help job seekers track and manage their job applications efficiently.

## Tech Stack
* **Backend:** FastAPI, Python, SQLAlchemy, SQLite, JWT Authentication, Bcrypt
* **Frontend:** React, Vite
* **API Documentation:** Swagger UI

## Features
* Secure user registration and token-based login.
* Add, view, and delete job applications.
* RESTful API architecture with automated Swagger documentation.
